# KTAPPI Text Mining

This repository provides Python code and supplementary data for the manuscript on research trend analysis of Scopus-indexed Journal of Korea TAPPI articles from 2000 to 2025.

The workflow includes:
- keyword cleaning and synonym merging
- keyword frequency and keyword evolution analysis
- keyword co-occurrence network analysis
- LDA topic modeling
- topic trend and life-cycle analysis
- topic-level citation impact analysis

Nanofibril, cellulose nanofibril(s), CNF, cellulose nanocrystal(s), CNC, and related terms were merged into the broader term nanocellulose during keyword preprocessing.
